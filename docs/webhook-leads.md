# Ribak CRM — Webhook להכנסת לידים

מסמך למפתחי הבוט באינסטגרם. כל ליד שהבוט אוסף נשלח לנתיב אחד, והוא נכנס ל-CRM כליד חדש.

---

## 1. הנתיב

```
POST https://blanchedalmond-yak-848858.hostingersite.com/api/inbound/lead
```

| | |
|---|---|
| Method | `POST` בלבד |
| Content-Type | `application/json` (UTF-8) |
| Headers | `X-Webhook-Key: ff0ad2a8af3962ac3132f1c968ae82a7` |

**המפתח חייב לעבור ב-header.** אל תשלחו אותו ב-URL כ-query string — הוא ייכנס ללוגים של שרתי ביניים.

המפתח הזה הוא שלכם בלבד. לכל מקור יש מפתח נפרד, וניתן לבטל אחד בלי להשפיע על השאר.

---

## 2. גוף הבקשה

```json
{
  "name":       "ישראל ישראלי",
  "phone":      "052-800-4505",
  "text":       "היי, אשמח לפרטים על שבוע ניסיון",
  "username":   "israel_fit",
  "ad_id":      "120253445475510236",
  "source":     "אינסטגרם – ממומן",
  "notes":      "",
  "consent":    true
}
```

| שדה | חובה | הסבר |
|---|---|---|
| `phone` | ✅* | מספר נייד ישראלי. פורמט חופשי: `0528004505`, `052-800-4505`, `+972 52 800 4505` |
| `text` | ✅* | תוכן ההודעה. אם `phone` ריק, המספר מחולץ מתוך הטקסט הזה |
| `name` | מומלץ | שם מלא. אם ריק — ייכנס `@username`, ואם גם הוא ריק: "ליד מאינסטגרם" |
| `username` | מומלץ | שם המשתמש באינסטגרם, עם או בלי `@` |
| `ad_id` | מומלץ | מזהה המודעה שממנה הגיע ה-DM (ספרות בלבד). ראו סעיף 5 |
| `source` | לא | חייב להיות מהרשימה בסעיף 4, אחרת יוחלף בברירת מחדל |
| `notes` | לא | טקסט חופשי שייכנס לכרטיס |
| `consent` | לא | האם אישר/ה קבלת תכנים שיווקיים. ראו סעיף 6 |

\* צריך **או** `phone` **או** `text` שיש בו מספר. אפשר לשלוח את שניהם.

**מגבלות אורך:** `text` 1000 · `notes` 500 · `source` 40 · `ad_id` 32 ספרות.

---

## 3. התשובות

| קוד | גוף | מה זה אומר |
|---|---|---|
| `201` | `{"ok":true,"created":true,"id":"..."}` | נוצר ליד חדש |
| `200` | `{"ok":true,"created":false,"id":"..."}` | המספר כבר קיים — נוספה הערה לליד הקיים |
| `200` | `{"ok":true,"created":false,"reason":"no_phone"}` | אין מספר נייד ישראלי בהודעה — **לא שגיאה** |
| `401` | `{"error":"unauthorized"}` | מפתח שגוי או חסר |
| `503` | `{"error":"webhook_not_configured"}` | תקלה בצד השרת — פנו אלינו |

**חשוב:** הודעה בלי מספר טלפון מחזירה `200` ולא שגיאה. זה מכוון — כדי שתוכלו להעביר **כל** הודעה נכנסת ולתת לשרת להחליט, בלי שהלוג שלכם יתמלא בכשלונות.

**אל תנסו שוב (retry) על `200` או `201`.** נסו שוב רק על `5xx` או timeout, עם exponential backoff, ועד 3 ניסיונות.

## 4. ערכי `source` מותרים

```
אינסטגרם – ממומן
אינסטגרם – משפיען
המלצה
אתר
וואטסאפ
אחר
לא ידוע
```

שימו לב: המקף הוא **en-dash** (`–`, U+2013) ולא מקף רגיל. ערך שאינו ברשימה יוחלף אוטומטית.

אם נשלח `ad_id`, המקור נקבע ל-`אינסטגרם – ממומן` אוטומטית ואין צורך לשלוח `source`.

---

## 5. `ad_id` — זיהוי המודעה

הקמפיין מריץ כ-11 יצירות במקביל, ו-`ad_id` הוא הדרך היחידה לדעת איזו מהן הביאה לקוח משלם.

במודעות Click-to-Instagram-Direct, מטא מעבירה לשיחה referral payload הכולל `ad_id`. אנא קראו אותו משם והעבירו כמות שהוא.

**אם המזהה לא זמין אצלכם — אל תמציאו ואל תשלחו ערך ריק.** עדכנו אותנו, ונעבוד לפי מזהה קמפיין במקום.

---

## 6. `consent` — הסכמה לדיוור

`true` / `false`. מתקבלים גם `"true"`, `"1"`, `"yes"`, `"on"`, `"כן"`.

אם אין בבוט שאלת הסכמה — השמיטו את השדה לגמרי (אל תשלחו `false` כברירת מחדל).

הערך נרשם בציר הזמן של הליד עם חותמת זמן, כהוכחה לפי סעיף 30א לחוק התקשורת.

---

## 7. התנהגות שחשוב להכיר

**זיהוי כפילויות לפי טלפון.** אותו מספר לא ייצור ליד שני. פנייה חוזרת מוסיפה הערה לכרטיס הקיים ומחזירה `created:false` עם ה-`id` המקורי.

**הקרדיט נשאר אצל הראשון.** אם אותו אדם מגיע שוב ממודעה אחרת, שיוך המודעה המקורי נשמר והחדש נרשם רק כהערה.

**רק ניידים ישראליים.** `05x` בלבד. קווי בית ומספרים מחו"ל יוחזרו כ-`no_phone`.

## 8. בדיקה

```bash
curl -i -X POST \
  https://blanchedalmond-yak-848858.hostingersite.com/api/inbound/lead \
  -H 'Content-Type: application/json' \
  -H 'X-Webhook-Key: ff0ad2a8af3962ac3132f1c968ae82a7' \
  -d '{"name":"בדיקה","phone":"0500000000","text":"בדיקת חיבור","ad_id":"120253445475510236"}'
```

תשובה תקינה: `201` עם `created:true`.

לבדיקה שלא יוצרת ליד — שלחו הודעה בלי מספר:

```bash
curl -i -X POST \
  https://blanchedalmond-yak-848858.hostingersite.com/api/inbound/lead \
  -H 'Content-Type: application/json' \
  -H 'X-Webhook-Key: ff0ad2a8af3962ac3132f1c968ae82a7' \
  -d '{"text":"בדיקת חיבור בלבד"}'
```

תשובה תקינה: `200` עם `reason:"no_phone"`.

## 9. מה לא לעשות

- אל תשלחו את המפתח ב-URL
- אל תשלחו `ad_id` מומצא או ריק
- אל תנסו שוב על `200`/`201`
- אל תשלחו מספרים שלא התקבלו מהמשתמש עצמו
- אל תשלחו את אותו ליד פעמיים "ליתר ביטחון" — הזיהוי האוטומטי כבר מטפל בזה
