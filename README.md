# Ribak CRM

באוויר: **https://greenyellow-hare-727269.hostingersite.com** (Hostinger, נפרס אוטומטית מ-`main`)
גיבוי: https://nivribak-create.github.io/ribak-crm/ (GitHub Pages)

מערכת ניהול לידים עם אנליטיקת המרה מלאה – מליד חדש ועד סגירת מנוי.
אפליקציית ווב נטו: HTML/CSS/JS ללא שרת וללא build, עובדת בדפדפן ובטלפון (ניתן להתקין כאפליקציה במסך הבית).

## הפייפליין

| שלב | הנגדי (סיבות אובדן) |
|---|---|
| ליד חדש | מספר לא תקין · ליד כפול / לא רלוונטי |
| קיבל הודעת וואטסאפ | לא הגיב להודעת הוואטסאפ · לא ענה לשיחה הראשונה |
| קיבל שיחה ראשונה | לא מעוניין אחרי השיחה הראשונה · לא ענה לפולואפ · לא מתאים (מחיר / מיקום / שעות) |
| פולואפ | לא מעוניין אחרי הפולואפ · לא סגר שבוע ניסיון |
| סגר שבוע ניסיון | לא הגיע לשבוע הניסיון · ביטל את שבוע הניסיון · לא סגר מנוי אחרי הניסיון |
| סגר מנוי | ✓ |

בנוסף, "לא ענה" (ניסיון ללא מענה) נרשם בלי להוציא את הליד מהפייפליין, וקובע פולואפ למחר.

## מה יש בפנים

- **לוח בקרה** – KPI-ים, משפך עם דליפות לכל שלב (המשיכו / עדיין בשלב / אבדו), סיבות אובדן, לידים לפי שבוע, המרה לפי מקור, זמן חציוני בין שלבים, ניסיונות ללא מענה, ורשימת "לחזור אליהם היום". סינון לפי טווח (7/30/90 ימים/הכל) ולפי מקור. הניתוח הוא לפי קוהורטה – תאריך כניסת הליד.
- **פייפליין** – לוח קנבן לפי שלבים, כרטיס לכל ליד עם חיוג ווואטסאפ בלחיצה, פעולות "התקדם" / "לא ענה" / "אבד", וטור אבודים עם החזרה לפייפליין.
- **לידים** – טבלה עם חיפוש, סינון, מיון וייצוא CSV.
- **פרטי ליד** – היסטוריה מלאה (כל מעבר, ניסיון, אובדן והערה), פעולה הבאה, הערות.
- **נתונים** – גיבוי/ייבוא JSON, נתוני דוגמה, ערכת צבע בהירה/כהה.

## הרצה מקומית

זה אתר סטטי. כל שרת קבצים יעבוד, למשל:

```bash
python3 -m http.server 8765
```

ואז לפתוח `http://localhost:8765`.
(פתיחה ישירה של `index.html` מהדיסק לא תעבוד – הדפדפן חוסם ES modules מ-`file://`.)

## פריסה ב-GitHub Pages

האתר מתפרסם ישירות מענף `main` (Settings → Pages → Deploy from a branch → main / root).
כל push ל-`main` מעדכן את האתר תוך דקה-שתיים.

הכתובת: `https://<user>.github.io/<repo>/`.

## איפה הנתונים

הלידים נשמרים ב-`localStorage` של הדפדפן – כלומר במכשיר שבו עובדים. לגיבוי או מעבר בין מכשירים: **נתונים → ייצוא גיבוי**, ובמכשיר השני **ייבוא גיבוי**.
שכבת הנתונים מרוכזת ב-`js/store.js`, כך שאפשר להחליף אותה בבסיס נתונים משותף (Supabase / Firebase) בלי לגעת בממשק.

## מבנה

```

css/app.css           טוקנים (בהיר/כהה) וכל הרכיבים

js/model.js           השלבים, סיבות האובדן, המקורות
js/store.js           מצב + שמירה + כל הפעולות על לידים
js/analytics.js       חישובי המשפך והדוחות
js/charts.js          משפך, ברים, גרף עמודות (SVG)
js/lead.js            טופס ליד, דיאלוג אובדן, מגירת פרטי ליד
js/views/             לוח בקרה · פייפליין · לידים
js/sample.js          מחולל נתוני דוגמה
sw.js, manifest.webmanifest   PWA
```
